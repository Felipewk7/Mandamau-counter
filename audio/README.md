# Musicas Tema por Fase

Coloque os arquivos de audio nesta pasta com os nomes exatos abaixo.
Formatos suportados: .mp3 / .ogg / .wav

| Arquivo              | Fase           | Minigame           |
|----------------------|----------------|--------------------|
| fase1_kleber.mp3     | Fase 1         | Queda de Braco     |
| fase2_gwen.mp3       | Fase 2         | Quiz da Gwen       |
| fase3_sam.mp3        | Fase 3         | Esmaga do Sam      |
| fase4_claudio.mp3    | Fase 4         | Genius do Claudio  |
| fase5_felifep.mp3    | Fase 5 (Final) | Blackjack Felifep  |

A musica entra em loop automaticamente ao iniciar o minigame
e para quando o jogador sair ou vencer/perder.
